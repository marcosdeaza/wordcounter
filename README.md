# Práctica: Contador de Palabras en El Quijote

Este programa en C++ busca una palabra introducida por el usuario dentro de un archivo de texto (el primer capítulo de *El Quijote*) y cuenta cuántas veces aparece. Este ejercicio es útil para gestión de datos en ciberseguridad o data science debido a que podemos reciclar este código para bases de datos en csv por ejemplo.

## 📝 Enunciado

Haz un programa que le pida al usuario una palabra y busque en el primer capítulo de *El ingenioso hidalgo don Quijote de la Mancha* cuántas veces se utiliza dicha palabra y lo muestre por pantalla.

**Archivo necesario:** `Quijote_cap_1.txt`
